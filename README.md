# 💚 Mental Health Chatbot

An empathetic AI-powered chatbot built to provide a safe, non-judgmental space for users to express their feelings. It uses a fine-tuned language model (via Hugging Face `transformers`) to generate supportive responses and includes a simple web interface built with Streamlit.

## ✨ Features
- **Streamlit Web App** – clean and private chat interface.
- **Fine-tuned Transformer Model** (Hugging Face / causal LM) for empathetic, context-aware replies.
- **Empathy Dataset** (`empathy_data.csv`) – curated prompt‑response pairs for training / fine‑tuning.
- **Sidebar with Crisis Helplines** (national & international).
- **Disclaimer** to clarify that the chatbot is not a substitute for professional care.

🚀 Usage
Start the Streamlit chat interface:

bash
streamlit run app.py
Once the app launches in your browser:

Type a message in the input box (e.g. "I feel really anxious today").

The chatbot will reply with an empathetic response generated by the fine‑tuned model.

Use the sidebar to view crisis helplines or clear the conversation.

📊 Dataset
The file empathy_data.csv contains realistic user concerns and corresponding supportive replies. Each row follows the format:

text
prompt,response
I feel really anxious today, I hear you. Anxiety can feel overwhelming...
These pairs are used to fine‑tune a base causal language model (e.g. a smaller GPT‑2 or Phi‑2 variant) so that the chatbot learns to respond with empathy and validation.

🧠 Model & Training
Base model: a pre‑trained causal LM from Hugging Face (the notebook shows which exact model is used).

Fine‑tuning: the notebook loads empathy_data.csv, tokenises the prompt–response pairs, and fine‑tunes the model for text generation.

Generation parameters (see app.py): max_new_tokens=60, temperature=0.75, top_p=0.92.

⚠️ Disclaimer
The code in app.py includes a clear disclaimer:

"This chatbot is not a substitute for professional mental health care. If you are in crisis please contact a helpline."

The sidebar also lists national and international crisis helplines (e.g. Umang Pakistan, Rozan counselling, iCall, Crisis Text Line).
